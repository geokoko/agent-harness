# Measured onboarding

Run the advertised getting-started path in a disposable environment. Record the
time to the first working result and each required deviation. A corrected
command proves a workaround, not that the published instructions worked.

Separate observations into TESTED, PARTIAL, or INFERRED. Include reproducible
blockers, missing prerequisites, unclear errors, and the recovery cost. Do not
invent a competitive score or universal time target. An absent developer-facing
surface is a scope mismatch, not a failed onboarding result. Account creation,
paid calls, and real service changes still need matching authorization.
