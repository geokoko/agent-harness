# Topic note template

Use the sections that fit the requested artifact; retain every required source
detail even when it needs more space.

```markdown
# Topic
Sources: file and page anchors.

## Intuition
Problem solved and exercise-recognition cues.

## Definitions and formulas
Faithful statement; symbols, units, assumptions, and validity conditions.

## Exercise method
Recognition cue → formula → assumptions → substitution → result → trap.

## Worked example
General formula → numerical substitution → result with units.

## Proof method, when relevant
Separate statement from proof; show the reusable argument.

## Exam evidence
Observed past questions with sitting/year and source pages.
Separate observed recurrence from predictions.

## Source gaps
Illegible notation, conflicts, and required material not yet covered.
```
