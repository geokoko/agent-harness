# Harness audit

The current [registry map](docs/registry-map.md) reconciles the August harness,
the September tuning line and both rebuild proposals. See [build evidence](docs/build-evidence.md) for this local
candidate’s authorship and validation.

The historical [frontier harness audit](docs/frontier-harness-audit.md), written
for the Codex rebuild, contains the August harness's architecture, every skill
and major mechanism, exact source costs, its deletion decisions, dated primary
sources and historical evidence. It did not account for the divergent September
tuning line and is not the final migration map.

See [evaluation results and limitations](evals/README.md) for measured behavior;
source reduction alone does not establish better model performance.
